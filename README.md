# 시리즈 다운로드 장부

네이버 시리즈 작품의 다운로드수를 매일 자동 수집하고, 로컬 대시보드에서 추이를 확인하는 도구입니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `config.json` | 추적할 작품 목록 (이름 + URL) |
| `collect.py` | 수집 스크립트 — 실행할 때마다 오늘 날짜로 기록 |
| `run_collect.bat` | 작업 스케줄러용 실행 파일 (로그는 `collect_log.txt`에 쌓임) |
| `dashboard.html` | 대시보드 — 더블클릭으로 열기 (인터넷 없이 동작) |
| `data/records.json` | 원본 기록 (백업하고 싶은 파일은 이것 하나) |
| `data/data.js` | 대시보드용 데이터 (collect.py가 자동 생성) |

## 1. 작품 등록

`config.json`을 메모장으로 열어 작품을 등록합니다. 시리즈 작품 페이지 주소를 그대로 붙여넣으면 됩니다.

```json
{
  "works": [
    { "name": "내 작품 제목", "url": "https://series.naver.com/novel/detail.series?productNo=1234567" },
    { "name": "두 번째 작품", "url": "https://series.naver.com/comic/detail.series?productNo=7654321" }
  ]
}
```

`name`을 비워두면 페이지 제목에서 자동으로 가져옵니다. 작품 수 제한은 없습니다.

## 2. 동작 확인

```
python collect.py --dry-run
```

각 작품에 대해 `[성공] 작품명: 1,234,567` 이 나오면 정상입니다.
`[실패]`가 나오면 `python collect.py --debug` 로 다시 실행하면 원본 HTML이 `debug_N.html`로 저장되니, 그 파일을 확인하거나 공유해 주세요.

확인이 끝나면 `python collect.py` 로 실제 기록을 시작합니다. 첫 실행 시 예시 데이터가 실제 데이터로 교체됩니다.

## 3. 매일 자동 실행 (Windows 작업 스케줄러)

**방법 A — 명령 한 줄** (명령 프롬프트를 관리자 권한으로 열고, 경로만 바꿔서 실행):

```
schtasks /Create /SC DAILY /ST 09:00 /TN "시리즈다운로드수집" /TR "C:\경로\series_dashboard\run_collect.bat"
```

**방법 B — 화면에서 등록**:
1. 시작 메뉴 → "작업 스케줄러" 검색 → 실행
2. 오른쪽 "기본 작업 만들기" → 이름: `시리즈 다운로드 수집`
3. 트리거: 매일, 원하는 시간 (오전 9시 추천 — 같은 시간대에 수집해야 일별 비교가 정확합니다)
4. 동작: "프로그램 시작" → `run_collect.bat` 선택
5. 마침 → 만든 작업 우클릭 → 속성 → "사용자가 로그온했는지 여부에 관계없이 실행" 체크(권장)

컴퓨터가 꺼져 있던 날은 기록이 비지만, 대시보드가 누락일을 감안해 증가량을 계산하므로 문제없습니다.

## 4. 대시보드 보기

`dashboard.html`을 더블클릭하면 브라우저에서 열립니다.

- 기간 선택: 7일 / 30일 / 90일 / 전체
- 작품 칩 클릭: 표시/숨김 토글 (모든 그래프·표에 동시 적용)
- 일별 증가량, 누적 추이, 작품 간 비교 그래프
- 기록 원장 표 + CSV 내보내기 (엑셀에서 바로 열림)

## 자주 묻는 것

- **하루에 두 번 실행하면?** 같은 날짜 기록을 덮어씁니다 (마지막 값 기준).
- **작품을 나중에 추가하면?** 추가한 날부터 기록이 쌓입니다. 기존 기록에는 영향 없습니다.
- **데이터 백업은?** `data/records.json` 파일 하나만 복사해 두면 됩니다.
- **파싱이 갑자기 실패하면?** 네이버가 페이지 구조를 바꾼 경우입니다. `--debug`로 저장된 HTML을 보내주시면 파서를 고칠 수 있습니다.
